A dense one-page newspaper poster summing up 36 verified stories from Wednesday 18 November 2026: three large features (the APEC CEO Summit opening in Shenzhen, fresh drone attacks in the Gulf, Cyclone Akvan) each with a WHY IT MATTERS line, a 4-number by-the-numbers strip, an 18-panel numbered grid with region and category tags plus verification badges, a world map with 21 region-coloured pins across 6 continents, and a 15-item ALSO ON list. Every story happened or was first reported on 18 November 2026 and was checked against 2+ sources; disputed claims are attributed. The poster is drawn in poster.html (system fonts only, zero external resources, zero scripts, all artwork original) and shipped as entry.png; main.ts copies it to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
